# cliente-teste

Cliente fictício para o ensaio da fase 6 da plataforma VFR Tech (adicionar um cliente de ponta a ponta sem mexer no
código da plataforma). Não tem dados reais. Roteiro: `docs/fase6/roteiro.md` no projeto da plataforma.

- `app.py`: uma função pequena para as tarefas de ensaio mexerem.
- `test_app.py`: os testes (`python -m unittest`).
- CI: o job `checks` em `.github/workflows/ci.yml`, o check obrigatório da `main`.
